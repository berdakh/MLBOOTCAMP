# Notebooks

These `.ipynb` files are **generated** from `../notebook_src/*.py` by
`python tools/nbbuild.py`, and committed with outputs cleared. To change a
notebook, edit its source and rebuild. Never edit the `.ipynb` directly.

Open any of them in Colab from the table in the [main README](../README.md),
or locally with `jupyter lab`. Each notebook's first code cell sets up the
environment, and its second rebuilds anything earlier notebooks would have
produced, so the notebooks can be run in any order and in a fresh runtime.

Solutions are in [`../solutions/`](../solutions/README.md). Attempt each
exercise first: the self-check cells tell you whether your code is right
without showing the answer.
